# Analytical Outputs

This directory contains non-restricted, company-level analytical outputs generated during the research.

## Files

- `Company_Level_LDA_Topic_Distribution.csv` – company-level distributions of the 14 sustainability topics derived from the LDA topic-modelling analysis.

- `Company_Level_FinBERT_Sentiment.csv` – company-level aggregated FinBERT sentiment measures, including positive, negative and neutral probabilities and the Mean Sentiment Score.

These derived outputs were used in the subsequent statistical analysis alongside LSEG ESG performance measures.

The underlying LSEG ESG data and original corporate sustainability reports are not redistributed through this repository because of third-party access, licensing and/or copyright considerations.
